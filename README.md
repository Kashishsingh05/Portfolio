# Kashish Singh | Portfolio

A responsive, dark-themed portfolio built with **React, Vite, Tailwind CSS**, HTML and JavaScript.

## Features
- Mobile-first responsive layout with a collapsible navbar and active-section highlighting
- Project filtering and a validated contact form
- Lazy-loaded contact section, reduced-motion support, keyboard-visible focus
- All content in one file: `src/data.js`

## Run locally
```bash
npm install
npm run dev
```

## Customize
1. Open `src/data.js` and replace the placeholder GitHub, LinkedIn and LeetCode URLs.
2. Add repo/live links to each project.
3. Replace `public/Kashish_Singh_CV.pdf` when your resume changes.

## Deploy to GitHub Pages
1. Create a GitHub repo and push this project.
2. Run `npm run deploy` (builds and publishes the `dist` folder to the `gh-pages` branch).
3. In the repo go to **Settings → Pages**, set the source to the `gh-pages` branch, and your site goes live.
